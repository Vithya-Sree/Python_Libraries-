# NumPy and Pandas Exercises

## Overview

This repository contains practice exercises based on **NumPy and Pandas**.

The exercises cover basic array operations, Pandas Series operations, and DataFrame manipulation using simple real-world datasets.

## Exercises Covered

### 1. NumPy Array Operations

Using weekly temperature data to practice:

* Creating 1D and 2D NumPy arrays
* Checking array shape, data type, and size
* Converting Celsius to Fahrenheit
* Finding maximum, minimum, and mean temperatures
* Array indexing and slicing
* Extracting specific days and weekends
* Working with 2D arrays

### 2. Pandas Series

Using student marks to practice:

* Creating a Pandas Series
* Using custom indexes
* Indexing and slicing
* Using `loc` and `iloc`
* Boolean filtering
* Modifying Series values
* Removing values
* Calculating CGPA

### 3. Pandas DataFrame

Using transaction data to practice:

* Creating a DataFrame
* Viewing and exploring data
* Checking shape, columns, and data types
* Selecting columns
* Using `iloc` and `loc`
* Filtering rows using conditions
* Finding value counts and unique values
* Grouping data and calculating averages
* Modifying values
* Adding and deleting columns
* Removing rows
